SaaS — Control Plane na Collie

A Collie opera Cockpit, Control Plane, Postgres, RabbitMQ, Evidence Processor e o caminho de AI (quando contratado). No seu perímetro: MeshAgent e, nos cenários 1.2 e 1.4, o Gateway.

1.1

LLM Collie + Gateway Collie

No cliente: MeshAgent LLM: Collie Gateway: Collie

Quando escolher: quer IA gerenciada pela Collie e não quer operar Gateway, broker nem banco. Aceita egress HTTPS dos agents para endpoints Collie.

1.2

LLM Collie + Gateway no cliente

No cliente: Agent + Gateway LLM: Collie Gateway: cliente

Quando escolher: quer LLM Collie, mas o pull dos agents deve permanecer na sua rede — compliance, latência ou firewall. Você opera o Gateway HTTPS opaco; CP e AI ficam na Collie.

Topologia alvo. Compose e manifests atuais empacotam o Gateway junto ao Control Plane. Até existir pacote Gateway-only com túnel/conector Collie, use 1.2 como especificação de implantação e alinhe o desenho com a Collie. Para PoC imediata, o caminho suportado é 1.1 (Gateway na Collie).

1.3

Agent para engenheiros (sem LLM)

No cliente: MeshAgent LLM: nenhuma Política: blocked

Quando escolher: o time usa o Cockpit para incidentes, collect, logs e remediação HITL. Não quer — ou não pode — caminho de LLM. Menor footprint de AI no contrato SaaS.

1.4

LLM própria ou de terceiro + Gateway interno

No cliente: Agent + Gateway (± LLM) LLM: própria / terceiro CP: Collie

Quando escolher: dados sensíveis exigem LLM interna (Ollama/vLLM) ou API de terceiro na VPC. Gateway no perímetro; Control Plane e Cockpit continuam SaaS Collie.

Mesma nota de maturidade do 1.2. Split Gateway↔Control Plane é topologia alvo; o tooling atual ainda colocaliza Gateway com o CP. PoC imediata: 1.1. Implantação 1.4 exige alinhar conector/túnel e endpoint LLM com a Collie.

Full — stack no ambiente do cliente

Assinatura Full: Cockpit, Control Plane, Postgres, RabbitMQ, Gateway, agents e (conforme o cenário) AI Policy, Router e LLM rodam no seu ambiente.

2

Full com LLM Collie

Stack: no cliente LLM: Collie (túnel/endpoint)

Quando escolher: precisa de stack completa no datacenter ou cloud, com governança local, e quer crédito/endpoint LLM Collie sem hospedar o modelo. Compliance permite egress controlado só para inferência Collie.

3

Full sem LLM

Stack: no cliente LLM: nenhuma Política: blocked

Quando escolher: OpsMesh completo on-prem (Cockpit, agents, remediação HITL) sem chat ou guidance por LLM. Engenheiros operam a timeline. Menor superfície — sem Ollama, sem adapters cloud.

4

Full com LLM externa ou própria

Stack: no cliente LLM: Ollama / vLLM / BYO

Quando escolher: stack Full e modelo sob seu controle. Política local_only e/ou BYO cloud_* com allowlist de providers.

Rede (mínimo)

Cenário Egress do agent Ingress no cliente
1.1 / 1.3 HTTPS → Control Plane e Gateway Collie Nenhum (zero inbound no agent)
1.2 / 1.4 HTTPS → CP Collie; pull no Gateway local Gateway alcançável pelo agent; sync CP↔Gateway no cliente conforme contrato Collie (túnel/AMQP/JWKS)
2 / 3 / 4 HTTPS → Gateway e CP locais TLS nos serviços do CP conforme topologia

Depois do cenário, escolha a topologia (Docker, Kubernetes ou VMs). Empacotamento e playbook comercial são eixos independentes.
